# Global Watch — assistente geoespacial para café

Aplicação web em que o usuário entra com Google, envia uma imagem de satélite
multiespectral e conversa com uma IA sobre **áreas potenciais** de cultivo de
café. O resultado é potencial e não validado em campo.
