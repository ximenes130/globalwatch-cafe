# Fontes

`PublicSans.ttf`: Public Sans (fonte variável), do repositório google/fonts
(`ofl/publicsans/PublicSans[wght].ttf`), baixada em 30/10/2026. Licença SIL Open
Font License 1.1 (`OFL.txt`). Usada no rodapé e nos rótulos de `polygons.png`
(`app/processing/render.py`), porque a fonte embutida do Pillow não tem acentos.
